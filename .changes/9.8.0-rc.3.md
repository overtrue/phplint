
## 9.8.0-rc.3 - 2026-10-13

This third (and last) release candidate of the new version 9.8 follows changes 
accordingly to the [ROADMAP](https://github.com/overtrue/phplint/issues/253).

Any feedback will be greatly appreciated.

And if you want to help/contribute to make PHPLint 9.8 more stable, 
do not hesitate to add [new report](https://github.com/overtrue/phplint/issues) with title prefixed by `9.8 | `

> [!IMPORTANT]
> If your issue/report contains contextual information (to identify more easily the problem), 
> please provide the output of the `diagnose` command, or diagnostic printed after the `lint` command execution.
>
> Remember you can add what you want (with `PLINT_DIAGNOSTIC` environment variable). Read the Diagnose Manager user Guide to learn more.
>
> You may also read the [FAQ](https://github.com/overtrue/phplint/blob/9.8/docs/FAQ.md) if you begin with this version,
> or just migrate from version 9.7.x

### Highlights in this pre-version

- Commit [`9ca9b71`](https://github.com/overtrue/phplint/commit/9ca9b71db80f00cbfbaf0be34bd79ed71fab48d8) : The `diagnose` command is able to print information about the caching feature (use `PLINT_DIAGNOSTIC=cache`)
- Commit [`f064b2b`](https://github.com/overtrue/phplint/commit/f064b2be62ec6a75a7147fd57c4a61eed6ad6f4f) : Fixed a regression with caching feature since first RC
- Commit [`95a4e78`](https://github.com/overtrue/phplint/commit/95a4e78e883c0b349bc2b9c333bb604c6dcd5d32) : Introduces EventAwareInterface contract and extracted code from AbstractManager (to new EventAwareTrait)
- Commit [`c90e1a0`](https://github.com/overtrue/phplint/commit/c90e1a0d598949bb401a974ab2f81c4f37ecc934) : Allows to exclude some metadata from a collection
