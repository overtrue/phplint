
## 9.8.0 - 2026-10-19

### Goals

- Have in minds to [reduce vendor dependencies](https://github.com/overtrue/phplint/issues/217), as much as possible.
- Load extensions/plugins on demand.
- Have User Experience migration as smooth as possible.

Do not hesitate to read the [FAQ](https://github.com/overtrue/phplint/blob/9.8/docs/FAQ.md)
and the [Migration Guide](https://github.com/overtrue/phplint/blob/9.8/docs/migration.md).

### Highlights

- Parallel Processing: Speed up analysis on large codebases 
    using the CPU auto-detection of [`fidry/cpu-core-counter`](https://github.com/theofidry/cpu-core-counter) package
    or use the `-j,--job` flag.
- The `lint` command is now modernized and use the [Symfony invokable syntax](https://symfony.com/blog/new-in-symfony-7-3-invokable-commands-and-input-attributes).
- The [Console Argument Resolvers](https://symfony.com/blog/new-in-symfony-8-1-console-argument-resolvers) introduced with Symfony 8.1
    is now available in a compatible format for PHP 8.2 / Symfony 7.4 LTS, and PHP 8.4+ / Symfony 8.1
- A new Extension Architecture was introduced with five basic extensions/plugins :

    * `CacheManager` to handle all cached results runs (using `symfony/cache` package).
        > Read the [Cache Manager User Guide](https://github.com/overtrue/phplint/blob/9.8/docs/extensions/cacheManager.md)
        and learn more on architecture, if you want to contribute or adapt behaviors
        with the [Developer Guide](https://github.com/overtrue/phplint/blob/9.8/docs/architecture/extension/cacheManager.md).
    * `DiagnoseManager` to output diagnostic information either after running the `lint` command, or just with the `diagnose` command.
        > Read the [Diagnose Manager User Guide](https://github.com/overtrue/phplint/blob/9.8/docs/extensions/diagnoseManager.md)
        and learn more on architecture, if you want to contribute or adapt behaviors
        with the [Developer Guide](https://github.com/overtrue/phplint/blob/9.8/docs/architecture/extension/diagnoseManager.md).
    * `OutputManager` to handle results in different formats: `console` (default), `sarif`, `checkstyle`, `junit`, `json`.
        > Read the [Output Manager User Guide](https://github.com/overtrue/phplint/blob/9.8/docs/extensions/outputManager.md)
        and learn more on architecture, if you want to contribute or adapt behaviors
        with the [Developer Guide](https://github.com/overtrue/phplint/blob/9.8/docs/architecture/extension/outputManager.md).
    * `ProfileManager` to output a mini profiler information to identify what resources are consumed by PHPLint.
        > Read the [Profile Manager User Guide](https://github.com/overtrue/phplint/blob/9.8/docs/extensions/profileManager.md)
        and learn more on architecture, if you want to contribute or adapt behaviors
        with the [Developer Guide](https://github.com/overtrue/phplint/blob/9.8/docs/architecture/extension/profileManager.md).
    * `ProgressManager` to handle all progress bars format: `auto` (default) , `dots`,  `bar`, `indicator`.
        > Read the [Progress Manager User Guide](https://github.com/overtrue/phplint/blob/9.8/docs/extensions/progressManager.md)
        and learn more on architecture, if you want to contribute or adapt behaviors
        with the [Developer Guide](https://github.com/overtrue/phplint/blob/9.8/docs/architecture/extension/progressManager.md).
