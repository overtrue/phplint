
## 9.8.0-rc.2 - 2026-10-09

This second release candidate of the new version 9.8 follows changes 
accordingly to the [ROADMAP](https://github.com/overtrue/phplint/issues/252).

Any feedback will be greatly appreciated.

And if you want to help/contribute to make PHPLint 9.8 more stable, 
do not hesitate to add [new report](https://github.com/overtrue/phplint/issues) with title prefixed by `9.8 | `

> [!IMPORTANT]
> If your issue/report contains contextual information (to identify more easily the problem), 
> please provide the output of the `diagnose` command, or diagnostic printed after the `lint` command execution.
>
> Remember you can add what you want (with `PLINT_DIAGNOSTIC` environment variable). Read the Diagnose Manager user Guide to learn more.
>
> You may also read the [FAQ](https://github.com/overtrue/phplint/blob/9.8/docs/FAQ.md) if you begin with this version,
> or just migrate from version 9.7.x

### Highlights in this pre-version

A benchmark report is [available](https://github.com/overtrue/phplint/blob/9.8/docs/benchmarks.md) between version 9.7.2 and 9.8.0-rc.2

- Commit [`a81901a`](https://github.com/overtrue/phplint/commit/a81901afab504a0f13b0f29c54866212fd824d83) : Fixed the project autoloader to be compatible with global `_composer_autoload_path` variable defined by Composer bin proxy
- Commit [`7dc1d5d`](https://github.com/overtrue/phplint/commit/7dc1d5d0aaa6fe1c31c9feb815cff8c1ae7d3b5b) : Fixed a PHP error when `cache_manager` is not loaded and `cache` is asked
- Commit [`6ccc8e0`](https://github.com/overtrue/phplint/commit/6ccc8e0921ae6326a2abcfa23a83ed6e3998c2a3) : PHAR distribution do not check anymore the requirement before to run on a platform
- Commit [`013ec7c`](https://github.com/overtrue/phplint/commit/013ec7cd90b3e8ff76c3b517b69fb1b6afb3c1c8) : to help PHPLint 9.7 users to migrate easily to new version 9.8
- Commit [`7d109f7`](https://github.com/overtrue/phplint/commit/7d109f7b84d3e679325a87a792a8496d07275bcb) : restore the `cache` option for a smooth migration for PHPLint 9.7 users
